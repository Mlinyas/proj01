GIT NA PRÁTICA

Esse comando Cria um novo repositório Git dentro da pasta do seu projeto. Aqui está como usar o git init de forma básica: git init Para criar um novo repositório enquanto especifica o nome do projeto, use o seguinte comando: git init [nome do projeto]

Esse comando adiciona os arquivos que você deseja incluir no próximo commit: git add nome_do_arquivo

Salva as alterações adicionadas em uma nova versão do projeto: git commit -m "Adicionar novo recurso"

Envia os commits do seu computador para o repositório no GitHub. Por exemplo, se você deseja enviar as das alterações do repositório local chamado para o repositório remoto chamado “origem”: git push origem principal
